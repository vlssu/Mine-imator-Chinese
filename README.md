### 中文整合包（下载即用）

不想手动替换语言文件的话，可以直接到 [Releases](../../releases) 下载对应版本的整合包：解压即用，已内置简体中文语言文件、中文字体与中文命名的粒子预设（原版英文保留，在 `设置 → 语言` 里切换即可）。

维护流程：更新某个版本的汉化文件并打上形如 `2.0.2-CC1.0.14` / `2.0.2-SU1.0.14.0` 的标签后，GitHub Actions 会自动从上游拉取该版本的发行包、注入汉化文件与字体/粒子，并用同一标签发布整合包。VB 版没有公开仓库，需在 Actions 里手动运行 `发布中文版` 并填写 `asset_url`（发行包直链）。
